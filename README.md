# Game-Isa

Jogo de aventura educativo (RPG / terceira pessoa) para estudar as matérias da escola
explorando um mundo, ou uma cidade, e resolvendo desafios.

## Ideia
- Cada região do mundo corresponde a uma matéria; personagens e missões trazem perguntas e problemas.
- Progresso, pontos e conquistas por matéria.
- Hospedagem prevista: VPS própria.

## Próxima versão (preparar, não implementar agora)
- Multijogador: amigas no mesmo mundo, resolvendo desafios juntas.
- Ranking de pontos.
